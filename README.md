 * **Datenspeicherung:** Daten werden sicher in einer Datenbank gespeichert. Es werden keine privaten Nachrichten (DMs) oder Chat-Verläufe dauerhaft mitgelesen oder gespeichert, die nicht für die Kernfunktion des Bots notwendig sind.
 * **Weitergabe an Dritte:** Es werden niemals Daten an Dritte weitergegeben, verkauft oder für Werbung genutzt.

Diese Bedingungen können jederzeit angepasst werden, wenn Updates oder neue Funktionen des Bots dies erfordern. Die fortlaufende Nutzung des Bots nach einer Änderung gilt als Akzeptanz der neuen Bedingungen.
